# Storage — Self-Hosted Cloud Storage

A Drive-like cloud storage service (part of the [Lackoff](https://lackoff.com) app hub) — upload, organize, and share files from your own infrastructure.

## Features
- File upload, download & sharing
- **Per-user storage quota** (5 GB free tier per user)
- JWT-secured APIs, integrated with Lackoff SSO

## Tech Stack
- **Backend:** Node.js, Express, MongoDB
- **Auth:** JWT (Lackoff SSO)
- **Storage:** self-hosted on Linux
